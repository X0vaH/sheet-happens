# Sources du catalogue de sorts 2014

Révision : bce51b3958573819e3b842fbc0cd9524fe4bc2e1

Traduction française : https://raw.githubusercontent.com/5e-bits/5e-database/bce51b3958573819e3b842fbc0cd9524fe4bc2e1/src/2014/fr-FR/5e-SRD-Spells.json

Adaptations : sélection des sorts du Clerc et du Magicien de niveaux 0 à 3, noms harmonisés avec le projet et descriptions résumées en français. Les résumés ne reproduisent pas toutes les règles des textes complets, notamment certains effets aux niveaux supérieurs.
